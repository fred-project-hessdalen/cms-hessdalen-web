## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Navigation caching

Site navigation uses Next.js's Data Cache with a 60-second revalidation interval
and the `site-navigation` tag. The existing `/api/invalidate-cache` endpoint
invalidates that tag. Avoid a separate process-local navigation cache: it can
hide fetches during static generation and bypass tag invalidation. In particular,
using `revalidate: 0` behind such a cache can cause a static-to-dynamic runtime
error when the cache expires.

Run the navigation caching regression tests with:

```bash
node --test scripts/test-navigation-cache.mjs
```
